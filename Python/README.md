# Python
This session introduces the Python programming language, and explores its importance and use.

### Agenda

| Activity | Time |
|-|-|
| Warm-Up | 10m |
| Lecture | 20m |
| Break | 10m |
| Code-Along | 40m |
| Self-Paced Time | 30m |
| Formative Assessment | 10m |

### Learning Objectives
At the end of this session, students will be able to:

- Recognize the power of Python
- Create their own simple programs using Python
- Identify Python's key characteristics

## Warm-Up
Let students draw something using the [Turtle Drawing](https://hytop.onrender.com/pf/turtle-draw) tool. After a few minutes, students can share what they've drawn.

## Lecture
Present the [PowerPoint](Python.pptx), which is a quick overview of Python.

## Code-Along: Python Turtle
Facilitate the [code-along activity](PythonCodeAlong.md).

## Self-Paced Exploration
In the remaining time, students can explore, learn, and create. There are [several potential avenues](PythonSelfPacedExploration.md) to traverse.

## Formative Assessment: Blooket
End the session by facilitating the [Blooket quiz game](https://dashboard.blooket.com/set/6983962d7db566f2733fd7f5).
