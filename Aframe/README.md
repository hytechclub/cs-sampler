# 3D Worlds with A-Frame
Is this session, students will learn to build a 3D world with [A-Frame](https://aframe.io/).

### Agenda

| Activity | Time |
|-|-|
| Warm-Up | 15m |
| Videos | 15m |
| Code-Along | 30m |
| Break | 15m |
| Self-Paced Time | 45m |

## Warm-Up: 3D Modeling
Help the students walk through the [warm-up activity](./WarmUpTinkercad.md) where they will create their own 3D models. Once they've submitted their work, go through each model to see what they did!

## Videos
For this portion, play some videos to introduce some of the history of 3D, as well as the more modern A-Frame technology. OKay it's not that modern but it's more modern than the 90s.

### History of Pixar
Toy Story was the first feature-length 3D animated film, and it set the bar for all 3D animation to follow. The first video shares a bit of the history of Pixar.

[Click here for the video](https://www.youtube.com/watch?v=IYsJTJ--uoU)

### Old-School 3D Animation
Back in the day, it was very very difficult to create 3D animations. The next video provides an inside look into the actual software animators used to make Toy Story 2.

[Click here for the video](https://www.youtube.com/watch?v=5TqPl3MSSow)

### A-Frame!
Okay, enough history. The actual technology covered by this session is A-Frame, which basically lets you create 3D worlds using HTML. For this video, only **the first ~3 minutes** are really needed.

[Click here for the video](https://www.youtube.com/watch?v=jhEfT9YjLcU)

## Code-Along: 3D Worlds
Walk the students through the [code-along activity](https://hylandtechoutreach.github.io/coding-activities/AFrame3dWorlds/WorldbuildingCodeAlong.html). Students will open up the starter project and add some code to create their own custom world!

### Adding 3D Models to A-Frame Projects
It is possible to add 3D models into A-Frame worlds, but it is a little complicated. They have to be exported, uploaded / hosted in an accessible place, and then brought into the code.

[Here is one example project for this.](https://hytop.onrender.com/e/aframe4)

## Self-Paced Time
With any remaining time, students can continue to explore and learn!

### Hubs Exploration
Students can join a public hub room from [Hubs](https://demo.hubsfoundation.org/) to explore.

### More Resources
Students can check out additional [resources](./Resources.md).

### More Learning and Building
Students are encouraged to keep learning and building! They can try to make a new 3D model, follow a new tutorial, build out their A-Frame world, or anything else they would like.
