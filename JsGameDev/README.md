# Game Development with JavaScript
This session introduces Game Development in the lens of JavaScript.

### Agenda

| Activity | Time |
|-|-|
| Warm-Up | 20m |
| Presentation | 20m |
| Fill-In-The-Blank Activity | 20m |
| Break | 10m |
| POWER-UP Activity | 20m |
| Self-Paced Work | 20m |
| Formative Assessment | 10m |

With remaining time, students can continue updating their games. They can also explore the [resources](https://hylandtechoutreach.github.io/coding-activities/ThreeJs3dGame/Resources.html), or dive deeper into some of the examples from earlier.

During this time, they are also encouraged to share their work using the form linked on the [course homepage](../BOOKREADME.md).
