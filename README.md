# CS Sampler Course Overview
This course introduces a new computer science topic every week. The goal is to inspire students by showing them some of what's possible with code. Topics include Python programming, A.I., and Game Design. Each lesson is introductory in nature, so the course is suitable for students of all levels.

_content is currently under revision, but in the meantime, feel free to check out the [mcccc curriculum](https://github.com/hylandtechoutreach/mcccc), from which much of this course's content will be pulled._
