# CS Sampler Course Overview
This course introduces a brand new topic each week. It is designed to give a broad overview of topics in computer science, with the goal of inspiring students and showing them what's possible with code. Each lesson is introductory in nature, so students of all levels will be able to learn something new every session.

_content is currently under revision, but in the meantime, feel free to check out the [mcccc curriculum](https://github.com/hylandtechoutreach/mcccc), from which much of this course's content will be pulled._
