# Interactive Storytelling with Twine
In this session, students will learn how to use Twine to create interactive fiction - basically, online Choose Your Own Adventure stories.

### Agenda

| Activity | Time |
|-|-|
| Icebreaker | 15m |
| Lecture | 10m |
| Blooket | 10m |
| Break | 15m |
| Follow-Along | 40m |
| Self-Paced Work | 30m |

## Icebreaker
For the icebreaker, have students brainstorm different story ideas. This should be a "no bad ideas" brainstorm session - basically they should write down literally anything that comes to mind. [Worksheet](https://github.com/hylandtechoutreach/coding-activities/blob/main/InteractiveStorytelling/BrainstormIcebreaker.docx) (print out copies)

- Settings (places / times)
- Characters
- Subjects

After some time, have the students share their ideas. These can be used to inform the story for the follow-along.

## Lecture
Present [these slides](https://docs.google.com/presentation/d/1lFeoOZadvJEkXux9pJgDB_4iJeWdphyyJgPehN9uTQ8/edit?usp=sharing) to kick things off.

## Formative Assessment: Blooket
Facilitate the [Blooket quiz game](https://dashboard.blooket.com/set/68f79fdb7660bf32aef2ea65).

## Follow-Along Activity
For the [follow-along activity](https://hylandtechoutreach.github.io/coding-activities/InteractiveStorytelling/FollowAlong.html), get into Twine and start building a story with the students.

### Student-driven Stories
It will be beneficial to allow the students to drive the story-writing process. Take suggestions from them for the content of the story, the branches, the characters, etc. Make sure their suggestions are conducive to a story with at least one variable, and multiple branches reaching the same node.

An easy way to accomplish this is to make a "Day in the Life" story. Begin with the main character waking up. Have every branch eventually lead to the character going to bed at night. Throughout the day, choose to track some information that may change (e.g., the main character's **GPA**). This should allow room for creativity while covering all of the essential topics.

## Self-Paced Work
Students can continue working on their stories by following the [self-paced work](https://hylandtechoutreach.github.io/coding-activities/InteractiveStorytelling/SelfPacedWork.html) instructions. They can also see how it's possible to [share their stories](https://hylandtechoutreach.github.io/coding-activities/InteractiveStorytelling/SharingStories.html).
