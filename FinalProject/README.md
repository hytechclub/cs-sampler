# Final Project
For the final project, students should choose one of the tech topics covered in the earlier part of the semester and build something based on that. For example, they could make a game, a Python turtle project, a Twine story, or anything else! Presentations will take place the following week.

[This page](./StudentDesc.md) has clearer guidelines for students. The only requirement is that the project clearly represents at least two hours of work/effort - this is up to the discretion of the instructors. It is more about the process of development than the final product. If a student is focused on development for ~2hrs, and then presents what they did, then that constitutes a successfully completed project.

If a student is "done" in less than two hours, try to think of additional features they could add. There is _always_ more they can do. Here are some potential ideas:

- Add another level / page / chapter / screen
- Add some settings that the user can change
- Create some custom art assets using something like [Piskel](https://piskelapp.com/kids)
- Create a website for the project that explains it and links to it
- Make the project more [accessible](https://www.ada.gov/resources/web-guidance/)

If they are really done, they can work on a whole new project using a different starting tech.
