# Artificial Intelligence

### Agenda

| Activity | Time |
|-|-|
| Warm-Up | 15m |
| Critical Thinking | 15m |
| Chatbot Chatting | 15m |
| Break | 15m |
| Vibe Architecture | 45m |
| Gimkit Practice | 5m |
| Gimkit Play | 10m |

## Warm-Up: Vibe Drawing
Students should follow [the instructions](VibeDrawingWarmUp.md) to create a turtle drawing or an svg graphic using vibe coding. Submissions should go to the sheet linked on the [README](../README.md).

## Critical Thinking: Presentation & Discussion
Lead into the [presentation](https://docs.google.com/presentation/d/17HV9xQQEsQ_L2_14Ha3uzu1R3L7lllN20rhp1tqCneI/edit?usp=sharing), which includes several discussion questions as well as some key term definitions.

## Chatbot Chatting
Have the students play the [Turing Test game](https://turingtest.live/play/) or chat with the very old [ELIZA chatbot](https://web.njit.edu/~ronkowit/eliza.html).

## Vibe Architecture
Present the [Vibe Architecture](VibeArchitecture.md) activity. Help students along through each of the three parts. They are welcome to work together, or work individually.

## Gimkit Practice
Students can take some time to practice the Gimkit questions linked on the [lesson homepage](StudentDesc.md). These will be the questions used in the game.
