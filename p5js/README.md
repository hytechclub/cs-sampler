# Creative Coding with p5.js
This session is all about getting creative with code using [p5.js](https://p5js.org), the JavaScript version of [Processing](https://processing.org/). Taken from [2D Scene](https://github.com/hylandtechoutreach/coding-activities/tree/main/Processing2dScene#building-a-2d-scene-in-p5js-lesson-plan) and [Micro Lessons](https://github.com/hylandtechoutreach/coding-activities/tree/main/ProcessingMicroLessons#p5js-micro-lessons) coding activities, outlined like [this](https://docs.google.com/document/d/1KXK-27hVIUr81VsXL4pH1dmZmqRxCIzTZZ37BuIxNSQ/edit?tab=t.orp23ayo5sj7#heading=h.pd1gyc9vgo2b).

### Agenda

| Activity | Time |
|-|-|
| Presentation | 20m |
| Code-Along | 30m |
| Break | 10m |
| Bug Catching | 10m |
| Micro Lessons | 40m |
| Gimkit | 10m |

## Presentation
Start presenting the [Google Slides presentation](https://docs.google.com/presentation/d/1qI1nRh0afxfExw-63fHfYYUENfr_1iH_l5vfA4gFNW0/) to kick things off. Note that there is a warm-up as part of the presentation where students go to [openprocessing.org/discover](https://openprocessing.org/discover/#/trending) to find some cool examples of what's possible with Processing.

## Code-Along: 2D Scene
Help students walk through the [2D Scene Code-Along activity](https://hylandtechoutreach.github.io/coding-activities/Processing2dScene/CodeAlong2dScene.html).

## Bug Catching
Work with the students to find and fix some bugs on [this page](https://hylandtechoutreach.github.io/coding-activities/ProcessingMicroLessons/BugCatching.html). Fix the first one or two as a group, and then let students try to fix them on their own.

## Micro Lessons
There are a variety of [micro lessons](https://github.com/hylandtechoutreach/coding-activities/tree/main/ProcessingMicroLessons#p5js-micro-lessons) to present to the students. Each is linked from the [session homepage](./StudentDesc.md).

## Gimkit
End the session by presenting the [Gimkit quiz](https://www.gimkit.com/view/65fc762f3ee6c3002c0db3c3).
